# 🌐 Multi‑Language Translator (googletrans)

> A lightweight Python tool that harnesses the power of Google Translate to convert text between **100+ languages** in seconds.

[![Python](https://img.shields.io/badge/Python-3.6%2B-blue.svg)](https://www.python.org/)
[![googletrans](https://img.shields.io/badge/googletrans-4.0.0--rc1-green.svg)](https://py-googletrans.readthedocs.io/)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

---

## ✨ Features

- 🔁 Translates between **over 100 languages**.
- ⌨️ Simple interactive command‑line interface.
- 🧩 Easily extendable for batch processing, file translation or API integration.
- 📝 Supports both **source** and **target** language specification via ISO codes. (Table of supported examples included at the end!)

---

## 🚀 Installation

Clone your repository and install the single dependency:

```bash
git clone https://github.com/yourusername/translator.git
cd translator
pip install googletrans==4.0.0-rc1
